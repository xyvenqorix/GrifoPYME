## 🚀 ¿Qué es GrifoPYME?

**GrifoPYME** es un sistema de gestión diseñado para pequeños negocios que necesitan organizar sus ventas, productos y operaciones de una manera sencilla.

La aplicación permite trabajar con los datos localmente y cuenta con un sistema de activación mediante licencia.

---

# 🔐 Sistema de licencia

GrifoPYME utiliza un sistema de activación asociado al equipo donde se instala.

Cada equipo dispone de un identificador único:

```text
ID DEL PC
```

La licencia se genera utilizando este identificador.

### Tipos de licencia

**⏳ Licencia temporal**

Tiene una fecha de vencimiento determinada.

**♾️ Licencia permanente**

No tiene fecha de vencimiento.

---

# 🔑 ¿Cómo obtener una licencia?

## 1. Abre GrifoPYME

En la pantalla de activación aparecerá:

```text
ID DE ESTE PC
```

Copia ese identificador.

---

## 2. Contacta al desarrollador

📱 **WhatsApp: +53 56638178**

Puedes enviar:

```text
Hola, deseo adquirir una licencia de GrifoPYME.

Mi ID de PC es:

TU-ID-AQUÍ
```

---

## 3. Recibe tu licencia

Se generará una clave asociada al ID proporcionado.

Después solo debes introducirla en:

```text
ACTIVACIÓN DEL PROGRAMA
```

y pulsar:

```text
ACTIVAR LICENCIA
```
